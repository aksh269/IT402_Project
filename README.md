## Overview

This project presents a comprehensive forecasting study on the **daily closing price of Coca-Cola (KO) stock** (October 2009 – January 2024), developed as part of the *IT402: Applied Forecasting Methods* course at Dhirubhai Ambani University.

The pipeline progresses from classical statistical methods to advanced deep learning and probabilistic forecasting, with a key focus on:
- **Point forecasting** — predicting the next-day closing price
- **Interval forecasting** — constructing calibrated 95% prediction intervals
- **Sentiment augmentation** — evaluating the incremental value of GPT-derived news sentiment

---

## Dataset

| Attribute | Details |
|---|---|
| **Ticker** | NYSE: KO (Coca-Cola) |
| **Frequency** | Daily |
| **Date Range** | October 2009 – January 2024 |
| **Observations** | ~3,554 (raw) / ~1,969 (after sentiment integration) |
| **Features** | Open, High, Low, Close, Volume, Sentiment_gpt, News_flag, Scaled_sentiment |

**Sentiment signals** were generated by submitting summarised financial news articles to GPT-3.5-turbo, producing a score on a 1–5 scale. Missing sentiment values on non-news trading days were imputed using an **exponential decay function** towards a neutral baseline of 3.

**Train / Validation / Test Split** (chronological, no shuffling):
- 🔵 Training: 70% (~2009 – mid-2019)
- 🟠 Validation: 15% (~mid-2019 – early 2021)
- 🟢 Test: 15% (~early 2021 – early 2024)

## Methodology

### Stationarity
- Raw close price confirmed **non-stationary** via Augmented Dickey-Fuller test (ADF stat: −1.64, p = 0.46)
- **First differencing** applied → ADF stat: −17.93, p ≈ 0.000 ✅
- ACF/PACF analysis revealed near-random-walk behaviour, guiding initial ARIMA order selection to (0, 1, 0)

### Preprocessing Pipeline
```
preprocess.py  →  summarize.py  →  score_by_gpt.py  →  price_news_integrate.py
```
All steps performed in **strict temporal order** to prevent data leakage.

## Models

### Baseline
| Model | Description |
|---|---|
| Naive Forecast | Predicts next price = current price (random walk) |
| 7-Day Moving Average | Mean of last 7 trading days |

### Statistical Models
| Model | Notes |
|---|---|
| AR(1), AR(5) | Fitted on first-differenced series |
| ARIMA(p,d,q) | Orders (0,1,0), (1,1,0), (0,1,1), (1,1,1) evaluated |
| ARIMAX | With exogenous features: volume, sentiment, lag features, rolling means |

### Deep Learning Models
All recurrent models used **96 hidden units** with a fully connected head (96 → 32 → 1).

| Model | Variant |
|---|---|
| RNN | Base + Sentiment-augmented |
| LSTM | Base + Sentiment-augmented |
| GRU | Base + Sentiment-augmented |

Lookback windows evaluated: {30, 60, 90, **120**, 150} trading days.

### Probabilistic / Interval Forecasting
- **Quantile Regression** (pinball loss) for τ ∈ {0.025, 0.5, 0.975}
- **Gradient Boosting Regressor (GBR)** with quantile loss
- **LightGBM** with quantile loss
- **RNN / LSTM / GRU** adapted for interval forecasting

## Results

### Point Forecasting (Test Set)

| Model | MAE | RMSE | R² |
|---|---|---|---|
| Naive Forecast | 0.4656 | 0.6495 | 0.9492 |
| MA(7) | 0.8206 | 1.0690 | 0.8632 |
| AR(1) | 0.4335 | 0.6028 | 0.9747 |
| AR(5) | 0.4335 | 0.6029 | 0.9747 |
| ARIMAX + Rolling_Mean(5) | 0.5950 | 0.8838 | 0.9509 |
| RNN (Base) | — | 1.1507 | 0.8381 |
| LSTM + Sentiment | — | 1.2268 | 0.8160 |
| GRU + Sentiment | — | 1.2402 | 0.8083 |

> ⚠️ **Note on R²:** High R² in stock forecasting is often a consequence of price persistence, not genuine predictive skill. **RMSE is the primary evaluation metric.**

### Probabilistic Forecasting (Test Set)

| Model | MAE | RMSE | Coverage | Avg Width | PB Loss |
|---|---|---|---|---|---|
| GBR | 0.6961 | 0.8825 | **92.28%** | 2.54 USD | 0.1495 |
| LightGBM | 0.6518 | 0.8480 | 87.95% | **2.26 USD** | **0.1444** |
| GRU + Sentiment (lookback=120) | — | — | **93–94%** | ~5.15 USD | — |

### 🏆 Key Findings
1. **Price persistence dominates** — simple AR and Naive models achieve high R² due to autocorrelation, not skill.
2. **Sentiment is weak for linear models** — ARIMAX with sentiment showed marginal gains; non-linear models benefit more.
3. **Rolling mean is highly informative** for ARIMAX, acting as a proxy for local price level.
4. **GRU outperforms RNN and LSTM** for interval forecasting with the tightest intervals (~5.5 USD average width) at ~93–94% coverage.
5. **Optimal lookback window: 120 trading days** (~6 months of history) consistently yielded the best coverage–sharpness balance.
